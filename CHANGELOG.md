# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-11-12

### Added
- Initial project structure with professional organization
- YOLOv8 integration for person detection
- Configuration-driven architecture with YAML config files
- Modular code structure (detector, video_processor, config_utils)
- Video processing pipeline with resolution adjustment
- Progress tracking and statistics reporting
- Comprehensive documentation (README, ARCHITECTURE, CONFIGURATION)
- Unit test framework with pytest
- Example configurations and .gitignore
- Requirements management with requirements.txt
- Setup configuration for package distribution

### Features
- Person detection in video frames
- Customizable detection parameters via config
- Bounding box and label annotation
- Support for CPU and GPU inference
- Automatic aspect ratio preservation
- Multiple video codec support

### Documentation
- Detailed README with installation and usage instructions
- Architecture documentation explaining system design
- Configuration guide with all parameters explained
- Contributing guidelines
- Example configurations for different use cases
